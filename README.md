## Domain

Kartu Mahasiswa — merepresentasikan kartu identitas mahasiswa dengan atribut nama, NIM, program studi, fakultas, dan status kartu.

## Struktur Class

| Field | Tipe | Keterangan |
|---|---|---|
| `nama` | `String` | Nama mahasiswa |
| `nim` | `String` | NIM mahasiswa |
| `programStudi` | `String` | Program studi mahasiswa |
| `fakultas` | `String` | Fakultas mahasiswa |
| `statusKartu` | `String` | Status kartu mahasiswa |

## Method

| Method | Return | Keterangan |
|---|---|---|
| `tampilkanData()` | `void` | Menampilkan data mahasiswa |
| `ubahStatus()` | `void` | Mengubah status kartu |
